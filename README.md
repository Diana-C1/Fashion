# Fashion Classification with KGAT

## Overview
This project uses the Knowledge Graph Attention Network (KGAT) model to classify fashion items from the Fashion-MNIST dataset.

## Dataset
- **Source:** Kaggle (Fashion-MNIST)
- **Description:** A Zalando research dataset containing 70,000 grayscale images of 10 categories of fashion items (e.g., T-shirts, dresses, shoes).
